# データベース演習環境 — Practice

授業用のブラウザSQLite演習環境です。

## 機能

- ブラウザ内SQLiteでSQL実行
- SQLシンタックスハイライト
- SQLキーワード・テーブル名・列名の入力候補
- 行番号，括弧対応，自動閉じ括弧
- SQL例
- 実行結果の表表示
- テーブル一覧と行数（テーブル名を押すとSELECT文をエディタへ入力。自動実行はしません）
- スキーマ・外部キー表示
- 関係図表示
- 「初期状態に戻す」
- SQLファイル保存

## エディタの入力補助

入力候補はSQL文そのものを生成するものではなく，SQLキーワードと，
現在選択しているデータベースのテーブル名・列名を候補として表示します。
2文字以上入力した場合に候補を表示し，必要に応じて `Ctrl + Space`
（macOSでは `Cmd + Space`）でも候補を表示できます。

CodeMirrorが外部CDNから読み込めない場合は，通常のテキストエリアに
自動的にフォールバックし，SQLの実行自体は継続できます。
